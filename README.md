# ECHO: PARADOX — MVP 0.1

Phaser 3 + TypeScript + Vite 기반 시간 역설 퍼즐 액션 게임.

## 바로 실행

개발 서버를 실행한 뒤 브라우저에서 http://127.0.0.1:5173/ 에 접속하세요.

Windows에서 다시 실행:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

GitHub에서 내려받아 실행하기 (Node.js 22 이상 필요):

```sh
git clone https://github.com/kwackya-commits/echo-paradox.git
cd echo-paradox
npm install
npm run dev
npm run build
npm run preview
```

최초 개발 환경의 tools/node.exe와 node_modules는 저장소에 포함하지 않습니다. 저장소를 내려받은 환경에서는 Node.js를 설치하고 npm install로 의존성을 복원하세요.

## 첫 스테이지 플레이

1. 새로운 시간선을 선택하세요.
2. WASD / 방향키로 보라색 ECHO 발판으로 이동하세요.
3. 발판 위에 잠시 머무른 뒤, 10초가 되어 에코가 생기면 떠나세요.
4. 오른쪽 아래 금색 코어를 모으세요.
5. 과거의 에코가 발판에 도착하면 오른쪽 출구가 열립니다. 에코를 피해 탈출하세요.

SPACE 대시 / Q 에코만 2초 정지 / E 경로 미리 보기 / F 보스 상호작용 / R 버스트(13단계부터) / ESC 일시정지.
터치 기기에서는 조이스틱과 능력 버튼이 표시됩니다.

## 구현 범위

- 고정 60Hz 시뮬레이션, 600프레임 불변 에코 스냅샷, 반복 재생, 수명과 충돌 유예
- 8방향 정규화 이동, 벽 충돌, 대시, 체력, 무적, 사망과 재시작
- 에코 전용 발판, 코어, 출구, 레이저, 컨베이어, 붕괴 바닥
- 첫 스테이지를 포함한 20개 레벨 데이터 및 4종 보스 로직
- 스토리 / 무한 / 타임어택 / 서울 날짜 기준 일일 도전
- 메뉴, 챕터 선택, 업적, 메달, 기록, 난이도, 음량, 그래픽, 색상 보상
- 버전이 있는 localStorage 저장 및 잘못된 데이터 기본값 복구
- 직접 그린 수트 텍스처와 환경, 합성 효과음 및 간단한 음악 시퀀서

현재 MVP입니다. 20개 스테이지 전체의 정상 플레이 클리어와 보스 밸런스는 아직 검증되지 않았으며, 출시 완성본으로 간주하지 않습니다.

## 실제 검증 결과 (2026-11-05)

- PASS: TypeScript 검사 및 Vite 프로덕션 빌드
- PASS: Chrome Playwright 스모크 테스트 1개: 메뉴 로드 → 첫 스테이지 → 키보드 이동 → 600프레임 에코 생성 → 일시정지 → 재시작 → 모바일 크기 표시. 브라우저 JavaScript 예외 없음.
- NOT TESTED: 전체 20레벨 플레이 클리어, 각 보스 격파, 각 모드 장기 플레이, 실제 터치 입력, 다른 브라우저, 오디오 청취 및 60FPS 성능, 저장 손상 회복 동작

스모크 테스트의 에코 생성은 개발용 QA 훅으로 시뮬레이션을 빠르게 진행합니다. 실제 10초 대기 테스트는 포함하지 않습니다. QA 훅은 개발 서버의 ?qa에서만 노출되며 프로덕션 빌드에서는 제거됩니다.

```sh
npm run test:e2e
```

브라우저 테스트는 먼저 npm run dev 실행이 필요하며 playwright.config.ts의 Chrome 경로는 현재 Windows 환경 기준입니다.

## 배포

npm run build 후 dist/ 전체를 정적 호스팅(Netlify, Cloudflare Pages 등)에 업로드하세요. 서버/인증/온라인 랭킹은 사용하지 않습니다. base가 상대 경로여서 하위 디렉터리 배포도 가능합니다. 외부 Google Fonts가 차단되면 시스템 폰트로 대체됩니다. 현재 공개 배포는 수행하지 않았습니다.
